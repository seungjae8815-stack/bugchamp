## English

### Title
```
Update 1.0.20 — Bug grades, essence & growth potions
```

### Body
```
[ Bug grades ]
- Every bug now has a grade (Common to Legendary). Old 1-5 star potential becomes its grade
- Turn same-species bugs (larva or older) into essence, then use essence to raise grades. This replaces 3-bug merging
- Bugs raised before the update return essence for the bugs used on them
- Growth potion: add when raising a grade, +3 all stats each (max 3)
- Egg draw: Epic+ within 10, Legendary within 50

[ Please note ]
- Pet bonus now follows bug grade: low-grade pets get weaker, high-grade pets stronger. Raise the grade with essence to recover
- Duel and King Bug Contest stats are recalculated by grade, species and stat rolls, including the current Round 2 from now on. Scores already set stay

[ Gear & Forge ]
- Transcend now takes time (jelly to finish). Forge upgrades after transcending cost more per step
- Swapping to gear of the same grade keeps its stars

[ More ]
- Duel power shown for each bug in the collection
- League board shows the new promotion and reward rules
```

## 日本語

### タイトル
```
1.0.20 アップデート — 虫の等級・エッセンス・成長ポーション
```

### 本文
```
1.0.20 アップデートが配信されました。

[ 虫の等級 ]
- 虫ごとに等級(一般・高級・希少・英雄・伝説)ができました。以前のポテンシャル1〜5つ星がそのまま等級になります
- 同じ種の虫(幼虫以上)をエッセンスに変え、エッセンスで等級を上げます。以前の3匹合成の代わりです
- アップデート前に育てた虫は、これまで使った匹数分のエッセンスで戻ってきます
- 成長ポーション: 等級を上げるときに入れると、1個につき全能力値+3(1回3個まで)
- 卵ガチャ: 10回以内に英雄以上、50回以内に伝説確定

[ ご確認ください ]
- ペット効果も虫の等級に従います。低い等級のペットは弱くなり、高い等級のペットは強くなります。同じ種をエッセンスに変えて等級を上げると回復します
- 決闘と王虫選抜大会の能力値も、等級・種・能力値ロールで計算し直されます。開催中の第2回大会にも今から適用されます。すでに出した記録はそのまま残ります

[ 装備・工房 ]
- 工房超越に時間がかかります(ゼリーで即時完了)。超越後の工房等級アップは段階ごとに高くなります
- 同じ等級の装備に交換すると星を引き継ぎます

[ その他 ]
- 採集箱で虫ごとに決闘戦闘力が表示されます
- リーグ順位表に新しい昇格・順位報酬のルールが表示されます
```
