## 0. 사장님 요구

1. **종마다 모든 등급**이 있다 — "전설 장수풍뎅이", "전설 사마귀". 전설 2종만 반복되는 문제 해결.
2. **하위 등급을 많이 모아 합치면 상위 등급**(요정 합성처럼). 낮은 등급이 흔하니 필요 수를 크게 — 모을 이유.
3. 합성할 때 **성장물약**을 넣으면 올라간 등급의 능력치가 더 좋게 나온다.
4. 같은 종이라도 **능력치 최소~최대 롤**(장비 옵션처럼) — 좋은 벌레를 뽑는 재미.

## 2. 제안 구조

### 2.1 개체 등급 = 포텐셜을 등급으로 다시 읽는다

- 포텐셜 1~5 → **일반 · 고급 · 희귀 · 영웅 · 전설**(개체마다). 화면의 ★ 대신 등급 이름·테두리.
- 종의 `grade` 는 **종 희귀도**로 이름만 바꿔 드롭 확률·산란/부화 시간·뽑기 종 선택에만 쓴다.
  → 장수하늘소는 "잘 안 나오는 종"이고, 나온 장수하늘소는 일반부터 전설까지 다 있을 수 있다.
- **새 필드가 없다**(포텐셜 값 그대로) — 세이브·서버·구버전 호환이 지금 구조 그대로다.
  새 축을 따로 만들면 "등급"과 "포텐셜"이 화면에 둘 다 남아 유저가 헷갈린다.

### 2.2 종 기본 능력치 다시 맞추기(필수)

등급이 개체로 가면 종 사이 능력치 격차(최대 2.3배)를 줄여야 "전설 애사슴벌레"가 쓸모 있다.
- 종마다 **능력치 총합은 비슷하게**, 분배로 개성(장수말벌 = 공격·속도형, 장수하늘소 = 체력형).
- 종 희귀도는 총합에 약간만(예: 희귀한 종 +10% 안팎) — 귀한 종을 잡는 의미는 남긴다.
- 위에 **개체 등급 배율**을 곱한다(예시 — 시뮬로 확정): 일반 ×1.00 · 고급 ×1.15 · 희귀 ×1.35 · 영웅 ×1.60 · 전설 ×2.00.

### 2.3 개체 능력치 롤(장비 옵션처럼)

- 개체마다 체력·공격·방어·속도 **각각 종 기준값 × 0.85~1.15**(예시) 롤. 화면에 "능력치 품질 %"와 각 칸의 최소~최대 막대.
- **크기(무게)는 이미 롤이다**(종 범위 정규분포 — 결투 = 무게, 사냥 = 펫 기여 0.85~1.20). 새로 굴리지 않고 품질 막대의 다섯 번째 칸으로 보여 준다.
- **치명·회피·회복력·밀어내기 힘도 롤에 넣는다**(2026-10-11 사장님) — 타고난 값이 있고, 훈련 포인트는 그 위에 **더한다**.
  예: 타고난 치명 3% + 훈련 치명 칸. 엔진 확률 상한(회피·치명 `evadeMax`·`critMax` 0.6)은 그대로 — 타고난 값이 높은 개체가
  상한에 먼저 닿으므로 롤 폭·훈련 칸 효과를 함께 잰다(`duel_build_sim`).
- 저장: `IndividualBug` 에 롤 4칸(0~100 정수) 추가. 롤의 rng 소비는 **기존 롤 맨 뒤**에 붙인다(§2.1 이색과 같은 규칙 — 앞에 끼우면 같은 seed 의 짝짓기 결과가 바뀐다).
- 기존 개체(롤 없음)는 **id 해시로 결정론적 롤**을 준다(전부 50% 로 두면 옛 개체가 모두 평범해지고, 전부 높게 주면 신규보다 유리).
- ⚠️ 롤도 **기기 권위**라 세이브 편집으로 최대치를 만들 수 있다(곤충 위조 구멍과 같은 처지) — 서버 결투 팀 검증(`validateDuelTeam`)이 범위(0~100)만 자른다. 실물 경품 대회 상위권은 운영 확인.

### 2.4 등급 합성 — 많이 모아야 오른다

- **같은 종 · 같은 등급 N마리 → 한 등급 위 1마리.** 필요 수 예시(시뮬로 확정): 일반→고급 **5** · 고급→희귀 **5** · 희귀→영웅 **4** · 영웅→전설 **4**
  → 일반에서 전설까지 같은 종 **400마리**(5×5×4×4). 낮은 등급이 흔한 만큼 많이 모아야 한다.
  지금은 3마리씩 4번 = 81마리(실제 합성은 13마리 — 부분 합성) — 사장님 말씀대로 "많이 모으게" 하려면 늘린다.
- 정수 가치: 곤충 1마리 → 그 종 정수 **(등급 누적 비용)** 개(일반 1 · 고급 5 · 희귀 25 …) — "한 등급 위 1마리 = 아래 N마리"가 맞물린다.
- ⚠️ **종 희귀도 보정 필수**: 모든 종에 같은 수를 걸면 하루 ~200드롭 기준 흔한 종(종 확률 ~8.7%) 전설까지 ~24일,
  전설종(~0.5%) ~400일. → 희귀한 종은 필요 정수를 줄이거나 정수 가치를 키워 "흔한 종·희귀한 종 모두 전설까지 ○일"로 맞춘다
  (짝짓기·뽑기 획득분 포함해 시뮬로).
- **알은 정수로 바꿀 수 없다 — 애벌레 이상만**(2026-10-11 사장님 확정: 알을 바로 바꾸게 하면 키울 개체 하나만 부화시키고 부화기가 무의미해진다).
  지금 획득 경로는 **전부 알**이다(실시간 드롭·방치 드롭·채집망·알 뽑기·짝짓기·결제 상품 알) — 성충으로 바로 오는 건 옛 트랩 채집(화면 미사용)·개발자 도구뿐이라 규칙에 구멍이 없다.
- 그러면 **부화기가 정수의 관문**이다. **부화기는 지금 그대로 둔다**(2026-10-11 사장님 확정): 1→최대 5칸 · 일반 5분~전설 16시간 ·
  **수동 수령** · 부화 중인 알도 채집함 칸을 차지("부화 중" 표시). 자동 대기열·묶음 부화는 만들지 않는다 —
  불편함이 젤리 가속·부화기 확장·채집함 확장을 살 이유다.
- 대신 **정수 필요량을 부화기 처리량에 맞춘다**: 무료 유저(1칸 · 하루 몇 번 접속해 수동 수령)의 하루 부화 수 기준으로
  "전설까지 ○주"가 되게 잡는다. 칸·젤리로 가속한 유저가 더 빨리 가는 것이 상품(§2.8 "90일 표는 무료 유저 기준"과 같은 구조).
  시뮬에서 **무료·과금 유저의 대회 도달 차이**도 함께 잰다(실물 경품 — "돈 쓴 사람이 유리" 인상 점검).
- 알 상태에서 **등급·롤을 보여 준다**(어떤 알을 먼저 부화할지 고를 수 있게). 이색은 부화 뒤 정수로 바꿀 때 한 번 더 확인.
- ⚠️ 젤리 즉시 부화·칸 확장이 정수 → 결투 능력치를 앞당기는 폭이 커진다(지금도 "시간 판매"로 허용된 범주) — 사장님 결정.
- 등급을 올릴 때 키우는 개체의 롤: 칸마다 새로 굴려 **기존 값과 큰 쪽**을 갖는다(나빠지지 않는다).
  새로 굴리는 값의 바닥을 **성장물약이 올린다**(§2.5) — 물약을 넣을수록 좋아질 확률이 커진다.
- 투자한 개체(수련·훈련 포인트)는 지금처럼 재료에서 뺀다.

**⚠️ 채집함 50칸 문제 — "곤충 정수"로 푼다(추천)**

> 쉽게: 곤충을 칸에 쌓는 대신 **같은 종을 숫자로 적어 두는 통장**. 재료로 쓸 장수풍뎅이를 "정수로 바꾸기" → 칸에서 빠지고
> "장수풍뎅이 정수 +1". 모이면 아끼는 장수풍뎅이 1마리에 "등급 올리기" → 정수 N개(+물약) 소모, 한 등급 위.
> 카드 게임의 "중복 카드 → 가루 → 원하는 카드 강화"와 같다.

같은 종 400마리를 채집함에 들고 있을 수 없다(상한 50 · 세이브 크기 방어선, §2.1). 그래서
- 하위 곤충을 **"○○ 정수"(종별 숫자)** 로 바꿔 보관한다 — 칸을 차지하지 않는다(스킬 조각과 같은 별도 맵 필드).
- 합성은 "기준 개체 1마리 + 그 종 정수 N개(+ 물약)"로 한다. 자동 방생(등급 필터)도 재료 대신 정수를 주게 하면 방치 중에도 모인다.
- **유저 흐름**: 같은 종에서 롤 좋은 몇 마리를 "키울 개체"로 남기고(공격형·체력형 등), 나머지·하위 등급은 정수로 바꿔 그 개체를 올린다.
- 곤충 정리 = **분해(재료·태생 4★+ 젤리 — 지금 그대로) / 정수로 바꾸기**를 나란히 고른다. 기존 보유 곤충도 같다.
  자동 방생 필터도 "재료로 / 정수로"를 고른다. 기존 합성(같은 종 3마리 → 포텐셜 +1)은 **정수 등급 올리기로 대체**한다.
- ⚠️ **정수 → 젤리 경로 금지**: 정수로 올린 등급은 분해 젤리에 쓰지 않는다(`bornPotential` 기준 유지) — 합성 5★ 분해 무한 젤리 구멍(2026-09-30)과 같은 문제.
- 정수로 바꾸는 건 **선택**이다(직접 · 등급 필터 자동) — 좋아하는 하위 곤충은 채집함에 그대로 두고, 그 개체를 전설까지 키울 수 있다.
- 채집함 크기 근거: 곤충 1마리 ≈ 450바이트(2026-07 장애: 3만 마리 = 13.6MB). 100칸 45KB · 200칸 90KB · 500칸 225KB · 1,000칸 450KB(업로드 한도 1MB 의 절반).
  세이브는 60초마다 통째로 올라가 크기만큼 요금이 선형으로 는다 → **확장 상한은 200~300칸까지 올려도 된다**, 같은 종 수백 마리를 칸에 모으는 설계는 안 된다.
- ⚠️ 새 재화는 **새 `MaterialKind` 가 아니라 별도 맵 필드** — 구버전 앱이 모르는 재료 키에서 크래시가 났다(§2.8).

### 2.5 성장물약

- 등급 올리기에 넣는다. 넣은 수만큼 **새로 굴리는 롤의 바닥이 오른다**(예: 1개당 하한 +5%p, 최대 3개 = 하한 +15%p — 장비 다듬기 "정성"과 같은 결).
  기존 값과 큰 쪽을 가지므로 물약은 "좋아질 확률"을 사는 것이다.
- 상위 등급일수록 물약 효과가 커 보이게(전설 합성에 넣은 물약이 가장 가치 있음).
- **획득처는 무료 경로만**: 보스 처치 · 미션 · 심연 층 보상 · 정수 교환 등.
  ⚠️ 물약은 결투·대회 능력치를 올린다 → **젤리로 팔면 §2.8 "결투·대회에 결제 요소 금지" 위반**이다.
  팔고 싶으면 사장님이 예외를 따로 확정해야 한다(훈련 포인트 대기 시간처럼 "시간"만 파는 형태여야 함).

## 2.6 첫 계산(2026-10-11, 단순 모델 — 방향용)

가정: 하루 드롭 ~198알 · 종 확률 = 등급 가중치 ÷ 그 등급 종 수 · 1칸 수동 수령(활동 2시간 + 하루 4번 확인) · 한 종에 집중 ·
짝짓기·뽑기·여러 종 부화기 공유·채집함 압박 **미반영**. 모델: 세션 scratchpad `essence_model.py`(정식 시뮬로 옮길 것).

1. **야생 등급 분포를 바꿔야 한다** — 지금 포텐셜 분포(1★ 50 · 2★ 21 · 3★ 16 · 4★ 13%)를 등급으로 쓰면 알 8개 중 1개가 영웅이라
   흔한 종이 1~2일에 전설. 예시: 일반 80 · 고급 15 · 희귀 4 · 영웅 1 · **전설 0**(등급 올리기·뽑기·짝짓기로만).
2. 필요 정수별 기간(무료 1칸, 종 희귀도 정수 가치 보정 ×1/1.6/3/5.5/14 적용):
   5·5·4·4(400) → 흔한 종 6.6일 · 6·6·6·6(1,296) → 14일 · **6·6·6·10(2,160) → 약 24일**(전설 종 ~29일).
   앞 단계는 빨리 오르고 마지막(영웅→전설)에서 오래 모으는 구조.
3. 흔한 종은 **알 수가 병목**(하루 ~17알 — 1칸으로도 다 부화) — 5칸이 확실히 빨라지는 건 부화가 긴 희귀 종(15→12일).
   실제로는 20종이 한 부화기를 나눠 써서 칸 가치가 더 크다(정식 시뮬에서). 과금 가속은 뽑기·짝짓기·희귀 종 즉시 부화가 주.

## 2.7 정식 시뮬(2026-10-11, `docs/design_tools/grade_progress_sim.py` — 실데이터 · 1분 단위 120일)

넣은 것: 20종 알이 한 부화기를 나눠 씀 · 채집함 50칸(부화 중 포함) · 수동 수령(활동 2시간 10분마다 + 하루 4번) ·
짝짓기(키우는 개체 + 반대 성별 1마리, 부모 대기 = 산란 시간 × `breedingCooldownMult` 2.0) · 정수 6·6·6·10(전설 = 2,160) · 야생 등급 80/15/4/1/0.
**안 넣은 것: 알 뽑기**(뽑기 등급 확률을 정한 뒤).

| 짝짓기 자식 등급 | 흔한 종 무료 | 전설 종 무료 | 과금(부화5·짝5) |
|---|---|---|---|
| 지금 규칙(높은 부모 유지 60·상승 10·하락 30) | **3.7일** | 15.9일 | 3~16일 — **눈덩이**(오른 개체가 높은 등급 알을 낳아 정수 폭증) |
| 짝짓기 없음 | 27.5일 | 54일 | 무료와 비슷 |
| **야생 분포(등급 안 물려줌)** | **27일** | 52일 | 17~26일 · 전설 종 50일 |
| 부모 등급 −2 | 26일 | 46일 | 17~25일 |

→ **짝짓기 자식은 등급을 물려받지 않는다(야생 분포)** 가 목표(무료 3~4주 · 과금 최대 ~1.6배)에 맞는다. CLAUDE.md §2.5 포텐셜 상속 규칙 변경(승인 필요).
→ 전설 종만 길다(52일) — 정수 가치 ×14 → ×25 안팎으로 4주에 맞춘다.
→ 부화기 칸 확장 효과는 작다(흔한 종은 알 수가 병목) — 과금 가속은 주로 짝짓기 칸 + 뽑기.

## 3. 영향 범위(손봐야 하는 곳)

| 영역 | 바뀌는 것 |
|---|---|

| 세이브 | 롤 4칸 + 정수 맵 + 물약 — feat 올림, 서버가 구버전 업로드에서 저장본 값을 지킨다 |
| 젤리 장부 | 물약·정수에 젤리를 붙이면 `jelly_sim` 줄 추가 |

## 4. 기존 유저 이전

- 포텐셜 그대로 = 등급이 된다. **5★ 장수하늘소 → 전설 장수하늘소**, 3★ 애사슴벌레 → 희귀 애사슴벌레.
- ⚠️ **1~2★ 전설종**(장수하늘소·장수말벌)은 "일반·고급 장수하늘소"로 보인다 → "강등됐다" 체감. 선택지:
  (a) 그대로 + 안내 · (b) 이전 때 그 개체 등급을 한 단계 올려 준다 · (c) 정수로 보상.
- 종 능력치를 다시 맞추면 **지금 결투 방어팀 전력이 바뀐다** — 시즌 경계(월 09시)에 맞춰 배포.
- **펫 기여도 개체 등급을 따른다(2026-10-11 사장님 확정 "그대로")** — 2★ 전설 종 펫 28% → 5.5% · 3★ 영웅 종 18% → 11% ·
  5★ 흔한 종 4% → 32% · 5★ 전설 종 그대로. 포텐셜 낮은 전설 종을 펫으로 쓰던 유저는 사냥이 약해지므로 **출시 공지에 적는다.**

## 5. 진행 순서(단계별 승인)

1. **숫자 시뮬** — 등급 배율 · 종 능력치 재정규화 · 합성 필요 수(드롭률로 "전설 하나 만드는 데 며칠") · 물약 효과 → 90일 표·결투 승률·대회 웨이브 영향. **여기서 사장님 확정.**
2. core_models/core_save: 롤 필드 · 정수 · 물약 · 합성 함수(앱·서버 공용) + 테스트.
3. 서버: 결투 팀 검증 · 업로드 상한(정수·물약 급증) · 구버전 업로드 보존.
4. 앱: 등급 표시 · 롤 막대 · 합성 화면(재료·물약·결과 미리보기) · 정수 보관함.
5. 이전·공지 · CLAUDE.md 개정 · 출시(서버 먼저).

## 6. 사장님이 정할 것

1. 등급 배율(예시 1.00 / 1.15 / 1.35 / 1.60 / 2.00)과 롤 폭(예시 ±15%).
2. 합성 필요 수(예시 5·5·4·4) — 시뮬에서 "전설 1마리까지 며칠"로 보여 드린다.
3. **곤충 정수**로 채집함 문제를 풀지(추천) / 채집함에 실물로 모으게 할지 · 채집함 확장 상한을 200~300칸으로 올릴지.
4. 성장물약 획득처와 **젤리 판매 여부**(판매하면 §2.8 예외 확정 필요).
5. 1~2★ 전설종 이전 처리(a·b·c).
6. ~~부화기 보완~~ → 부화기 그대로(확정). 남은 것: 무료 유저 "전설까지 목표 기간"(예: 흔한 종 ○주 · 희귀 종 ○주).
