## 본문
```
캐릭터 탭 → 요정에서 만날 수 있어요. 요정 한 마리를 '동행'으로 데려가면 능력치가 오르고, 사냥 중에 스킬을 자동으로 써요.

[ 요정 8종과 스킬 ]
- 이그니스(공격): 큰 피해를 한 번에
- 운디네(체력): 체력이 60% 아래면 회복
- 테라리엘(방어): 잠시 받는 피해 감소
- 실피드(공격속도): 잠시 공격속도 증가
- 볼테아(치명 피해): 잠시 모든 공격이 치명타
- 루나리스(보스 피해): 보스에게 큰 피해
- 티타니아(곤충 피해): 잠시 곤충의 공격 강화
- 아스테리아(체력·방어): 쓰러질 때 한 번 버티고 다시 일어남

[ 얻는 법 ]
- 사냥터 보스를 처음 쓰러뜨리면 요정 알 확정 (난이도가 높을수록 높은 등급)
- 정예 몬스터에게서 가끔 알·속성석·가속기가 나와요
- 요정 뽑기 (젤리 30, 10회 안에 전설 확정)
- 알은 둥지에 넣어 부화시켜요 (일반 30분 · 희귀 2시간 · 영웅 6시간 · 전설 16시간). 가속기로 시간을 줄일 수 있어요

[ 등급과 능력치 ]
- 일반 · 희귀 · 영웅 · 전설 · 신화. 등급이 높을수록 기본 능력치와 스킬이 강하고 최대 레벨도 높아요 (Lv.10 ~ 50)
- 요정마다 '부가 능력치'가 하나 붙어요. 부화할 때 속성석을 넣으면 원하는 부가 능력치가 50% 확률로 나와요

[ 합성 ]
- 같은 종류 · 같은 등급 3마리를 합치면 한 단계 위 등급 1마리 (신화는 합성으로만 얻어요)
- 결과의 능력치는 새로 정해져요. 레벨을 올린 요정을 재료로 쓰면 쓴 가루의 70%를 돌려받아요
- 자동 합성은 동행 중이거나 레벨을 올린 요정은 쓰지 않아요

[ 요정 가루 ]
- 요정 레벨을 올리는 재료예요
- 요정을 분해하면 얻어요 (일반 5 ~ 신화 500)
- 요정 도감 보상과 상점 교환소에서도 얻을 수 있어요

요정함은 30칸이에요. 요정 도감에서 등급과 부가 능력치를 모으면 보상을 받아요.
```
