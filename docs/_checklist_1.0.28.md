## 1. 신규 유저 (새 게스트 계정으로)
- [ ] 쉬움 **첫 보스가 강화 100 근처에서 잡힘**(체력 5,000) · 사냥터 2 가 두 대에 죽는 벽이 아님
- [ ] 강화 **50레벨까지 재료 없이 골드로만** — 줄에 재료 비용이 안 보이고, 51레벨부터 재료가 붙음
- [ ] 처음 5번 부화는 **최대 5분** (희귀·영웅 알도) · 6번째부터 원래 시간
- [ ] 즉시 부화 · 즉시 산란 · 즉시 돌파 버튼이 **"첫 1회 무료"** · 누르면 확인 창 없이 바로 완료 · 두 번째부터 젤리 값
- [ ] 점심·저녁 일일보상이 열리면 **우편함 자동 열림** (시작 팝업·보스 직후와 안 겹침)
- [ ] 결투 티켓 처음 **5장** · 닉네임 추천 **5자리 숫자** · 게스트 재안내 안 뜸
- [ ] 버프 빨간 점이 버프 창을 한 번 열면 사라짐(쉬움 동안 꺼진 황금 러시만 남음) · 새 곤충 발견 **창은 처음 3종**, 그 뒤는 띠 안내
- [ ] 첫 실행 **둘러보기 9칸**(강화·사냥터·버프·편지함·미션·채집함·결투·상점·⇄) → 끝나면 편지함 · 둘러보는 동안 안 맞음
- [ ] 탭마다 **첫 방문 안내** 한 번(채집함·장비·결투·상점·스킬·요정·연구소) · 다시 들어가면 안 뜸 · 미션 줄 누르면 그 자리 안내(제련 → 모루)
- [ ] 강화 효과가 늘어나는 숫자로: "골드 수입 +A% → +B%" · "몬스터에게 N대 버텨요 → M대" · 선물·일일 재료가 골드보다 작게(1/3)
- [ ] 사냥터 1 보스 클리어 창 "**사냥터 1 보스 … 격파! 다음 사냥터가 열렸어요**" · 그 뒤 안내 창 하나만(리뷰는 사냥터 4부터)
- [ ] 두 번째 미션 "**능력 강화**" · 편지함 보상 줄이 재료 아이콘별(키틴·미네랄·수액)
- [ ] 사냥터 2 보스(질 게 뻔함) 버튼 "**자동 멈춤**" · 누르면 "**강해지는 법**"(버프·편지함·추천 강화 · 그래도 도전)
- [ ] 쓰러져 내려오면 "추천 강화: …" · 강화를 하나 사기 전엔 자동 도전 안 함 · 사냥터 2부터 **장비/펫 첫 안내** 한 번씩
- [ ] 깜짝 선물 도착 띠 안내 · 30분 남으면 한 번 더 · 추천 줄 꾹 누르기는 추천이 바뀌면 멈춤

## 2. 캐릭터 강화
- [ ] 강화 패널 위 **+1·+10·+100·최대 버튼이 없음** · 한 번 누르면 1레벨, 꾹 누르면 연속
- [ ] 제목 줄이 **"이름 Lv.N/최대"만** — 좁은 화면에서도 안 잘리고 안 넘침
- [ ] **추천**은 아이콘 아래 노란 배지 · 보스에게 지면 안내에 "추천 강화: …"
- [ ] 값 줄 끝에 **"· 각성 Lv.N"** · 닿으면 값이 한 번에 뜀 + "각성!" (치명·회피 줄은 없음)
- [ ] 효과 한 줄(몬스터 N대 → M대 · 보스 약 N초 → M초 · 한 대 N% → M% · 골드 수입 +N%)
- [ ] 가끔 **"대성공! +1레벨 덤"**
