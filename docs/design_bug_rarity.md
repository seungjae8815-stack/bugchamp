# 곤충마다 희귀도 (1.0.22 안 — 2026-10-16 사장님 요청)

## 무엇을 바꾸나
- 지금: 희귀도가 **종에 고정**(장수하늘소·장수말벌 = 늘 전설, 전설 종이 두 종뿐).
- 바꾼 뒤: 희귀도가 **곤충마다** 정해진다. 같은 장수말벌도 일반·고급·희귀·영웅·전설이 따로 나온다.
  **개체 등급(일반~전설, 정수로 올리기)은 그대로 따로** 있다 — 곤충 하나 = 종 × 희귀도 × 개체 등급.

## 사장님 확정 (2026-10-16)
1. 희귀도가 바꾸는 것 = **정수·분해 가치 · 부화·짝짓기 시간 · 펫 패시브 크기 · 결투·사냥 능력치**
2. 확률 = **모든 종 같은 표**
3. 이미 가진 곤충 = **한 번 새로 굴린다**
4. 짝짓기 자식 = **야생과 같은 확률**(부모 희귀도 안 물려줌)

5. (2026-10-16 추가 확정) 확률 표 A **그대로** · 결투 차이 = **같은 종·같은 개체 등급·같은 훈련에서 전설 희귀도가 일반을 65%** 이기게(지금 54% 보다 키움) ·
   도감에 종마다 **최고 희귀도** 기록 추가(표시·기록만, 보상은 나중).
   ⚠️ 뽑기 전설 희귀도 17%(야생 1%)라 결투 차이를 키운 만큼 결제 유저가 결투에서 유리해진다 — 사장님 인지하고 65% 선택.

## 설계 (확정)

### A. 확률 표
| | 일반 | 고급 | 희귀 | 영웅 | 전설 |
|---|---|---|---|---|---|
| 야생·짝짓기 | 52 | 28 | 14 | 5 | 1 |
| 알 뽑기·결제 알 | 0 | 25 | 30 | 28 | 17 |

- 야생 표 = 지금 드롭의 종 희귀도 비율(`dropGradeWeights`) 그대로 → **전설이 나오는 빈도·정수·젤리 경제가 지금과 같다.** 종은 20종이 똑같이 5%씩.
- 뽑기 표 = 지금 뽑기 희귀도 비율(`gachaWeights`) 그대로. 전설 천장도 그대로.

### B. 희귀도 → 능력치
- **사냥(펫 기여)**: 1.0.20 부터 펫 기여는 개체 등급으로만 정해지고 종 희귀도는 안 들어간다(종 기본 능력치도 안 쓴다).
  그래서 펫 기여에 희귀도 배율을 **새로 곱한다** — 일반 0.90 · 고급 1.00 · 희귀 1.15 · 영웅 1.35 · 전설 1.60
  (사장님 확정 2026-10-16 "평균 1 맞추기" — 야생 확률로 평균 ≈ 0.99 → 평균 유저 사냥·90일 표 그대로, 전설 희귀도 펫 +60%).
  패시브 크기는 지금처럼 `rarityFactor`(0.57~1.0)를 곤충 희귀도로 읽는다.
- **결투·대회**: 능력치 = 종 기본 × 종 배율(`gradeScale`) × 개체 등급 × **희귀도 결투 배율** × 롤.
  종 배율은 종끼리 50% 로 다시 맞추고(지금은 종 희귀도 기울기 46~54% 를 넣어 맞춘 값), 희귀도 결투 배율은
  **전설 희귀도 대 일반 희귀도 65%** 가 되게 맞춘다(희귀도 사이는 고르게 · `duel_build_sim`). 대회 종 배율도 다시 맞춘다.

### C. 정해지는 방법 (서버·구버전 안전)
- 희귀도 = 곤충 칸 `ry`(정해서 줄 때 — 뽑기·희귀 천장) 또는 **곤충 id 로 정해지는 롤**(없을 때 — 야생·짝짓기·업데이트 전 곤충,
  뽑기 출신 `gc` 이면 뽑기 표). 앱·서버가 같은 함수(core_run `BugRarityConfig.rarityOf`)로 계산한다.
  서버는 `ry` 를 **새 id 에만** 허용한다(`ng` 와 같은 처리). 위조는 지금 개체 롤과 같은 수준(조작 앱이 id 를 골라 만드는 것은 못 막는다).
- 기존 곤충 "새로 굴리기" = 같은 함수가 기존 id 에도 적용되는 것. 따로 이전 작업이 없다.

### D. 함께 바뀌는 곳
드롭(종 고르기) · 뽑기·결제 알·스킨 알 · 부화기·짝짓기 타이머와 젤리 즉시완료 값 · 정수 `essenceRarity` · 패시브 v2 `rarityFactor` · 결투·대회 능력치 ·
펫 기여 · 도감(종별 기록에 "최고 희귀도" 축 추가 여부) · 채집함 색·정렬·필터(희귀도 필터는 곤충 희귀도로) · 자동 방생 재료 · 분해 젤리 문턱 ·
서버 `_enforceGrade` 정수 검사 · 시뮬(`balance_sim`·`duel_build_sim`·`grade_progress_sim`·`jelly_sim`).

## ⚠️ 위험 — 기존 곤충 새로 굴리기
- 전설 종(장수하늘소·장수말벌)을 가진 사람의 약 **99%가 전설을 잃는다**(새 표에서 전설 1%). 영웅 종도 95%.
- 그 곤충에 정수를 들여 등급을 올렸으면: 능력치·패시브·정수 되돌림 값(전설 ×28 → 일반 ×1)이 한꺼번에 내려간다 — "업데이트하고 약해졌다" 클레임 1순위.
- 반대로 일반 종 곤충의 약 48%는 희귀도가 오른다.
- **결정(2026-10-16 사장님): C — 그대로 다시 굴리고 공지만.** 정수 보상은 의미가 없다(정수는 개체 등급 재료라 희귀도를 되돌려 주지 못한다).
  출시 공지에 반드시 적는다: 모든 곤충의 희귀도를 새로 정함 · 장수하늘소·장수말벌도 이제 어떤 희귀도로든 나온다 · 어떤 종이든 전설이 나올 수 있다.

## 희귀도 올리기 (2026-10-16 사장님 확정 — "같은 종 같은 희귀도 재료")
- 곤충 하나 + **같은 종 · 같은 희귀도 곤충 3마리**(재료, 사라짐) → 그 곤충 희귀도 +1(전설까지). 키운 것(등급·롤·훈련·패시브)은 그대로.
  무료 경로 — 일반 → 전설 = 같은 종 81마리 안팎. 젤리로 팔지 않는다(결투 능력치 — §2.8).
- 재료 제외: 장착·부화 중·훈련·잠금·투자한 곤충(합성 재료 규칙 `pinnedBugIds`·`isPreciousBug` 와 같다). 알 제외(부화기를 거치게).
- 정수 무한 증식 없음: 일반 3마리(정수 3) → 고급 1마리(1.6) — 올릴수록 정수 가치가 줄어든다.
- 저장: 올린 곤충은 `ry` 에 새 희귀도. 서버는 같은 id 의 `ry` 가 오르면 **이번 업로드에서 사라진 같은 종 · 그 단계 희귀도 곤충 3마리씩**이 있어야 인정한다(아니면 저장본 값).
- 마릿수(3)는 `pets.json → bugRarity.upFodder`.

## 1.0.22 에 함께 들어간 것 (2026-10-16 사장님 요청)
- **희귀도 올리기**(위 절) — `core_save/bug_rarity_up.dart` · 서버가 재료 3마리 사라짐을 확인하고, 재료로 쓴 곤충은 정수 허용치에서 뺀다 · 곤충 상세 "희귀도 올리기 n/3".
- **경기장 오행**(`docs/design_arena_element.md`) — 같은 오행 +10% · 경기장이 이기는 오행 −10%. 결투는 제안 때 서버가 정해 보여 주고 경기를 치를 때까지 유지(다시 굴리기 방지),
  대회는 회차 seed + 웨이브. 엔진 `simulateBout(arena:)` 한 곳. 대회 평균 18.8웨이브(경기장 없을 때 18.5).
- **놓친 능력치 굴리기**(문의) — 업데이트 전 곤충은 (등급 − 1 − 새 규칙으로 올린 단계)번 무료로 롤을 굴린다(등급 올리기와 같은 규칙, 물약 +3점). 곤충 `lru`, 서버가 줄지 않게 지킨다.
- **결투 티켓 무료 충전은 상한까지만**(가득이면 막고 하루 횟수도 안 씀) — 예전엔 넘겨 쌓여 매일 모아 둘 수 있었다. 앱·서버 `freeTickets`.
- **훈련 배분 편집 ＋/－ 누르고 있으면 반복**(0.35초 뒤부터 빨라짐).
- **장비 별 줄**(다음 별 n/200)이 좁은 칸에서 다음 줄로 내려간다.
- **장비 다듬기 v3** — 새 값은 늘 지금보다 높다 · 비용은 그 줄을 다듬은 횟수마다 ×1.5(`forge.json → polishCostGrowth`) · 최대면 막는다.
