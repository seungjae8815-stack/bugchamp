# 길드 — 협동 미션 · 길드 보스 · 상점 · 버프 · 주간 길드전 설계

> 2026-09-30 사장님 방향:
> - **미션**: 하루 3회, 선택지 여러 개. 보상은 재료. 참여할 때 **대기 1·3·10분**을 고르고, 그 사이 들어온 길드원이 **부족한 전투력을 채워 준다**.
> - **길드전**: 7일 한 판. 날마다 **다른 활동 경쟁**(1일차 짝짓기·부화·합성 / 2일차 제련 등급 점수 … 7일차 전투력 대결).
>   승점이 높은 길드가 이긴다. **승리 = 보상 전부, 패배 = 승리 보상의 절반**. **길드 티어**로 비슷한 길드끼리 붙고, 이기면 올라간다.
> - 길드 보스 · 상점 · 버프 스킬도 넣는다.
> ⚠️ 수치는 **초안**. `[결정]` = 사장님 결정 대기.

## 0. 지키는 선 (헌법에서 온 것)

1. **길드 상태는 전부 서버가 소유**한다(길드·멤버·미션·길드전 점수·코인). 세이브(기기 권위)에는 `guildId` 캐시만 둔다.
   보상은 **우편(`user_mail`)으로 보낸다** — 기기 권위 세이브에 서버가 직접 재료를 넣는 새 경로를 만들지 않는다(iOS 지급 방식과 같다).
2. **돈이 길드전 승패를 정하지 않게** 한다(§2.8). 활동 점수는 **멤버별 하루 상한**이 있고, **젤리로 당긴 완료는 세지 않는다**(§4.3).
3. **젤리는 유한한 통로에만**(§2.6): 길드전 결과(주 1회)·길드 보스 주간 순위만. 미션·기부·출석에는 없다. `jelly_sim` 에 줄부터 추가.
4. 길드 버프는 **적응형 기준 밖**(§7)이고 90일 표에 축을 넣는다. 결투·대회에는 안 싣는다.
5. **숙제가 되지 않게** — 하루 할 일 = 미션 3 · 보스 2 · 길드전 그날 과제(평소 하던 행동이 점수가 됨). 새 행동을 강요하지 않는다.

## 2. 길드 미션 (하루 3회 · 협동)

### 2.1 흐름
1. 매일 09:00(시즌 경계와 같은 KST 기준) **미션 게시판 5개**가 뜬다(길드 공통 seed — 모두 같은 목록).
2. 하나를 골라 **출발**. 이때 **대기 1분 · 3분 · 10분** 중 고른다.
3. 대기 중인 미션은 길드 화면·길드 채팅에 **"도움 요청"** 으로 뜬다. 다른 길드원이 **도와주기**를 누르면 전투력이 더해진다(최대 3명).
4. 시간이 끝나면 **서버가 판정**: 합산 전투력 ≥ 요구 전투력 → 성공(보상 우편), 모자라면 **부분 보상**(비율만큼, 최소 30%).
   - 요구를 넘으면 **바로 성공**(시간을 다 기다릴 필요 없음). `[결정]`

### 2.1-b 구현 확정(2026-10-01, 2단계)
- **보상은 우편이 아니라 미션 탭의 "보상 받기"**(사장님 확정) — 우편은 화석·요정 알을 못 싣고 하루 8통이 쌓인다.
  지급은 우편 수령과 같은 순서: 앱이 최신 세이브를 올림 → 서버가 수령 기록(`guild_mission_claims`)을 먼저 남기고 서버 세이브에 넣음 → 앱이 채택.
- **2026-10-01 사장님 수정**: 게시판은 **길드원마다 다르다**(유저·날짜 seed). 돕는 사람 몫에 **상한 없음**(내가 약해도 센 길드원 한 명이 도와주면 깬다). 전투력이 요구를 넘어도 **시간은 끝까지 흐르고** 그때 합산으로 판정, **도움 3명이 다 모이면 전투력과 무관하게 그 자리에서 성공**. 혼자 출발 즉시 성공(×0.8 칸)은 그대로이고 **대기 배율 1**(10분을 골라도).
- 실패 보상 = 배율 × 달성률 × 0.5. **"최소 30%" 는 뺐다** — 넣으면 ×3.5 칸 혼자 실패(1.05)가 ×0.8 칸 성공(0.8)보다 많이 받는다.
- 돕는 사람 보상 = **자기 사냥터 기준** × 50% — 출발자 사냥터로 주면 쉬움 유저가 극한 친구를 도와 재료를 수천 배 받는다(`1.008^스테이지`).
- 전투력은 앱이 보내는 홈 상단 값. 출발자는 부풀려도 요구치가 같이 오른다. 돕는 쪽은 상한이 없어 부풀린 값으로 남의 미션을 깨 줄 수 있지만 얻는 건 재료·코인이고 하루 도움 보상 5회로 막힌다(젤리 없음).
- 한 번에 진행 중 미션은 1개. 도움 요청은 길드 채팅에 카드(`#help:<id>`)로 뜬다(서버가 넣는다). 보상 기한 7일.
- 수치: `guild.json → mission`, 규칙 `core_run/lib/src/guild_mission.dart`, 서버 `guild_mission_actions.dart`.

### 2.2 미션 난이도 = 내 전투력 기준
- 난이도마다 전투력 규모가 수만 배 달라 **고정 요구치가 성립하지 않는다**(골드를 정액으로 못 쓰는 이유와 같다).
- 요구 전투력 = **출발한 사람의 전투력 × 미션 배율**. 게시판 5개의 배율은 예: ×0.8(혼자 가능) · ×1.3 · ×1.8 · ×2.5 · ×3.5(도움 필수).
- 보상은 배율에 비례하고, 규모는 **출발한 사람의 사냥터** 기준(재료 수량 규칙 `1.008^스테이지` 를 그대로).
- 대기 시간이 길면 보상도 조금 오른다(1분 ×1.0 · 3분 ×1.1 · 10분 ×1.25) — 오래 기다린 대가.
- ⚠️ 돕는 사람의 전투력은 **요구치 대비 비율로 자른다**(한 명이 요구치의 60% 까지만) — 최상위 한 명이 모든 미션을 혼자 끝내면 협동이 아니다.

### 2.3 보상
- 출발한 사람: 재료(키틴·미네랄·수액·화석) + 길드 코인 + 낮은 확률 요정 알.
- 도와준 사람: **출발자 보상의 50%** + 길드 코인. **하루 도움 보상 5회**(그 뒤로도 도울 수는 있고 보상만 없다 — 돕는 게 손해가 되지 않게).
- 길드 경험치 +.
- ❌ 젤리 없음(하루 8번 × 길드원 수 = 무한 통로).

### 2.4 전투력 출처
- `profiles` 에 올라가는 `displayCombatPower`(업그레이드·레벨·펫) — **기기 권위라 위조 가능**. 미션 보상은 재료뿐이라 **서버 골드·재료 상한과 같은 수준의 방어**로 둔다
  (업로드 상한 + 전투력 급증 감지). 길드전 7일차는 이걸 쓰지 않는다(§4.4).

### 2.5 서버
- `guild_missions(id, guild_id, owner, board_slot, mult, wait_sec, need_power, started_at, ends_at, helpers jsonb, settled)` · 판정은 **끝난 뒤 첫 조회 때**(cron 없음 — 대회·시즌과 같은 구조).
- 앱은 **길드 화면이 열려 있을 때만** 10초마다 조회(`/guild/missions`). 화면 밖에서는 길드 채팅 알림(Realtime)으로 "도움 요청" 을 받는다.
  ⚠️ 폴링 주기·대상은 Cloud Run 요금에 선형 — 화면 밖 폴링 금지.

## 3. 길드 보스 (주간 · 체력 공유)

- 주 1마리(월 09 ~ 일 09). 체력은 **길드가 공유하고 이월**된다(AFK Arena·Tap Titans 2 방식). 체력 = 길드 평균 전투력 × 인원 × 배율(길드마다 다른 체력 — 규모 차이 흡수).
- 1인 **하루 2회**. 한 번 = 30초 자동 전투. **피해는 서버가 계산**한다(`/guild/boss/attack`): 앱이 피해를 보내게 두면 누구나 1위다.
  - 피해 공식 입력 = 서버가 확인할 수 있는 값 — `[결정]` A안 결투 방어팀 능력치(서버 `validateDuelTeam` 이 이미 검증함) · B안 `displayCombatPower`(위조 가능, 간단).
- 개인 보상 = **피해 구간 상자**(AFK Arena 방식 — 약한 유저도 첫 상자는 받는다) · 처치하면 **전원 보너스**(처치 단계 1~5, 다음 단계는 더 단단한 보스).
- 길드 보스 **주간 순위**(길드끼리, 같은 티어 안): 1~10위 젤리. 유한 통로 → `jelly_sim` 한 줄.

## 4. 길드전 (7일 · 티어 매칭)

### 4.1 일정 — 시즌 시간표를 그대로
- **월 09:00 매칭 → 일 09:00 마감 → 24시간 정산 → 월 09:00 새 대전**(`battle_config.dart` 의 `seasonStartAt`·`settleSeasonIdAt` 재사용).
  결투 시즌·심연과 같은 경계라 "이번 주" 가 한 가지 뜻이 된다.
- 하루 = 09:00 ~ 다음 날 09:00. 7일차 = 일요일 09:00 이전의 마지막 24시간 → **정산 24시간은 결과 발표·보상 수령**.
  `[결정]` 월~일 7일 + 정산은 다음 주 월요일 오전(= 새 대전과 겹침) 대신, **6일 경쟁 + 7일차 전투력 대결**로 7일 안에 끝내는 쪽을 추천.

### 4.2 날마다 다른 경쟁 (초안)
| 일차 | 주제 | 점수 | 멤버 하루 상한 |
|---|---|---|---|
| 1 | 육성 | 짝짓기 시작 10 · 부화 수령 10 · 합성 1회 3 | 100 |
| 2 | 제련 | 제련 결과 **장비 등급별**: 풀잎 1 · 나무 2 · … · 호박 200 (지수) | 300 |
| 3 | 사냥 | 정예 처치 · 보스 처치 · 사냥터 클리어 | 200 |
| 4 | 결투 | 결투 승리(서버 확정 결과만) | 5판분 |
| 5 | 수련 | 곤충 수련 레벨업 · 훈련소 단계 · 스킬 수련 | 150 |
| 6 | 길드 보스 | 길드 보스에 넣은 피해(서버 계산) | 2회분 |
| 7 | **전투력 대결** | §4.4 | — |

- 1~6일차: 그날 **길드 점수 합이 높은 쪽이 승점 1**(`[결정]` 점수 차 비율로 0~2 승점). 7일차 = 멤버 대결 승 1개당 승점.
- ⚠️ **멤버 하루 상한**이 핵심이다. 없으면 한 명의 고래가 길드 점수를 혼자 만들고, 길드전이 "누가 더 결제했나"가 된다. 상한이 있으면 **"몇 명이 참여했나"** 가 승부가 된다 — 길드전을 만든 이유(접속 유도)와 맞다.
- ⚠️ **젤리 즉시완료로 끝낸 부화·짝짓기는 점수 0**(§0-2). 제련은 화석 소비라 결제와 무관 — 단, 화석을 쌓아 두었다 2일차에 몰아 치는 것은 **허용**(준비한 대가). 하루 상한이 한 번에 몰아 칠 수 있는 양을 자른다.
- ⚠️ 활동 대부분이 **기기에서 확정**된다(합성·제련은 서버 경로가 없다). 앱이 보낸 카운트는 위조 가능 → **하루 상한 + 서버에 경로가 있는 행동(짝짓기·부화 수령·결투·보스)은 서버가 센다**. 위조로 얻을 수 있는 최대치 = 상한이라 피해가 제한된다.
  `[결정]` 합성·제련을 서버 경로로 옮길지(비용 큼) / 상한으로 버틸지(추천).

### 4.3 점수 전달
- 앱: 행동이 일어날 때 로컬 카운터(`guildWarTally{day, counts}`) → 60초 주기 `/save` 업로드에 **같이** 실어 보낸다(새 요청을 만들지 않는다 — 요금).
- 서버: 업로드에서 **그날 몫 증가분만** 받아 `guild_war_scores(week, guild_id, user_id, day, score)` 에 누적, 하루 상한으로 자른다.
  서버 경로가 있는 행동(결투·보스·짝짓기·부화)은 앱 카운트를 무시하고 서버가 센 값을 쓴다.

### 4.4 7일차 — 전투력 대결
- 양 길드 멤버를 **결투 방어팀 전투력 순으로 1:1**로 짝짓는다(1위 대 1위 …). 인원이 다르면 남는 쪽은 **부전승 없음**(승점 0 — 인원 늘리기 경쟁을 막는다).
- 대결 = **결투 엔진(`simulateDuel`)을 서버가 돌린다** — 방어팀 3마리 대 3마리. 전투력 숫자 비교가 아니라 실제 결투라 **약한 쪽의 여지**(§2.3)가 있고 결과를 다시 볼 수 있다(재생).
  - 결투 방어팀은 이미 서버가 검증하고 부위 강화·훈련을 상한으로 자른다 → 위조에 가장 강한 값.
  - ⚠️ 요정·스킬·장비는 **싣지 않는다**(결투와 같은 선 — 뽑기가 승패를 정하지 않게).
- 7일차 참가 = 방어팀을 등록한 멤버 전원(자동). 그날 할 일은 **없다** — 응원·결과 보기만. `[결정]` 7일차에 방어팀을 바꿀 수 있는 마감 시각.

### 4.5 승패 · 보상
- 승점 합이 높은 길드 승리. 동점이면 **7일차 대결 승수 → 1~6일차 점수 총합**.
- **승리 = 보상 100%, 패배 = 50%**(사장님 확정). 보상 = 길드 코인 + 재료 + 젤리(티어별, 초안 브론즈 10 ~ 다이아 40 · 멤버 1인당). 우편으로.
- 받을 자격: 그 주 월요일 09:00 **이전에 가입** + 그 주 점수 1 이상.

### 4.6 길드 티어 · 매칭
- 브론즈 · 실버 · 골드 · 플래티넘 · 다이아(결투 리그와 같은 이름).
- **길드 등급점(GR)**: 승리 +30 · 패배 −20 (티어 경계에서 승급/강등). 새 길드는 브론즈 0점.
  `[결정]` B안 결투 리그처럼 티어 안 상위 20% 승급·하위 20% 강등 — 길드 수가 적을 때는 GR 쪽이 덜 흔들린다.
- 매칭: 같은 티어 · 가까운 GR · **길드 전투력(상위 20명 방어팀 합)** 가 비슷한 순. 직전 상대와는 안 붙인다.
- 홀수·짝 없음 → **가상 길드**(같은 티어 평균 점수를 따라 하는 봇)와 붙인다. 보상은 같다.
- 참가 조건: 월 09:00 기준 멤버 5명 이상.
- ⚠️ 출시 초 길드 수가 적으면 티어 안에서 짝이 안 맞는다 → 이웃 티어까지 넓히고, 그래도 없으면 가상 길드.

## 5. 길드 레벨 · 버프 스킬
- 길드 경험치: 출석 기부(하루 1회, 재료 소량) · 미션 · 보스 · 길드전 참가.
- 레벨마다 인원 +1 · **길드 스킬 포인트 +1**. **길드장이** 스킬에 찍는다(모두에게 적용, 2026-10-05 — 예전엔 부길드장도).
| 길드 스킬(초안) | 최대 |
|---|---|
| 공격력 % | +8% |
| 체력 % | +10% |
| 골드 획득 % | +10% |
| 재료 획득 % | +10% |
| 부화·산란 시간 −% | −10% |
| 미션 보상 % | +20% |
- 반영 = 온라인 방치 런 + **오프라인 정산은 골드만**(2026-09-30 사장님 확정 — 방치가 주 플레이라 빼면 체감이 없다. 2026-10-05 현행화: 재료 버프는 오프라인에 넣지 않는다 — §7.5).
  - 오프라인 골드는 기기 캐시(`GuildBuffCache`)로 앱이 건다 — 서버 settle 의 길드 조회는 만들지 않았다(§7.5).
  - ⚠️ 서버 골드 상식 상한(`clamp_check`)에 길드 골드 %를 넣는다 — 안 넣으면 정당한 수입이 잘린다.
  - 공격력·체력 % 는 오프라인 정산에 영향이 없다(정산은 처치 속도를 전력으로 잰다 → `[확인]` 정산 공식이 전력을 쓰는지 구현 때 본다).
- ⚠️ **적응형 기준 밖**(§7) · 결투·대회 X · 90일 표에 `guildFillByDay` 축.
- 길드를 나가면 버프가 즉시 사라진다(나가기 비용).

  - 멤버 등급 = `guildMemberRank(guild.json → memberRanks, contribution)`(core_run 공용, 새 DB 칸 없음). **혜택·권한 없음.** 하루 코인 약 80~240 기준
    일꾼 약 5일 · 정예 약 4주 · 원로 약 3개월. 탈퇴하면 기여도와 함께 사라진다(새 길드는 새내기부터).
  - 앱: 멤버 탭 맨 위에 내 등급·다음 등급까지 남은 기여도·직책별 권한 도움말(i), 멤버 줄마다 등급 뱃지. 뱃지 그림은 `assets/images/ui/guild/rank_{id}.webp`
    (없으면 아이콘 — 그림을 넣을 때 pubspec assets 에 `assets/images/ui/guild/` 줄을 함께 넣는다). 길드장 앱바 메뉴에 "부길드장 가입 수락 허용" 스위치.
    멤버 줄 메뉴(임명·위임·추방)는 길드장에게만 열린다.
