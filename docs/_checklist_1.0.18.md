# 1.0.18 확인 체크리스트 (1.0.17 → 1.0.18 변경 전체)

> 기준: 커밋 13bc829(1.0.17) 이후 ~ 345cee6. 폰 확인은 **개발용 앱 + 시험용 서버(bugchamp-server-dev) + 오리 계정**으로.
> 길드는 닫힌 채(`kGuildOpen` false)로 나간다 — 길드 탭은 "준비 중"이어야 한다.

## A. 사냥 · 보상 (모든 유저가 바로 체감)
- [ ] 깜짝선물이 **1·2·3시간치**로 크게 들어온다(편지함에 "사냥 N분치" 문구는 없어야 함)
- [ ] 깜짝선물 2배 받기(하루 1회 무료, 2~4배) · 그날 첫 2배에 젤리 1~5
- [ ] 일일보상 점심 **3시간치** · 저녁 **5시간치**, 받은 뒤 "한 번 더 받기"까지 들어온다
- [ ] 받고 1~2분 뒤 골드가 되돌아가지 않는다(서버 상한에 안 잘림)
- [ ] 교환소 "젤리 10 = **5시간** 사냥한 만큼" 문구·금액, 교환 뒤 골드 유지
- [ ] 쉬움 단계가 빨라졌다(사냥터 1~3 몬스터·보스가 전보다 약함)
- [ ] 패시브 스킬 효과 그림(채집가의 손·곤충학자의 눈·끈기·군집)이 6초마다 옅게 보인다
- [ ] 강화 상한: 공격·체력·방어 **250**, 공속 125, 치명 피해 110, 보스 피해 105 까지 살 수 있다

## B. 보스 · 진행 (신규 유저 막힘 해결)
- [ ] 게이지 100마리가 차면 버튼에 "3초 뒤 자동 도전" → 자동으로 보스전
- [ ] 처음 게이지가 찼을 때 안내 팝업 1번("보스가 나타났어요!")
- [ ] 도전 버튼이 빨강·노랑 테두리로 크게 반짝인다
- [ ] 설정 → 게임 → **보스 자동 도전** 끄면 수동으로 돌아간다
- [ ] 다른 탭에 가 있거나 팝업이 떠 있으면 자동 도전이 멈춘다
- [ ] 최종 보스 직후 다음 난이도 사냥터 1~10 이 "깬 것"으로 잘못 기록되지 않는다(버그 수정)
- [ ] 로드맵에서 위 난이도를 누르면 뜨는 팝업 글씨가 잘 보인다
