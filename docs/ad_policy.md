# 광고 운영 수칙 — 무효 트래픽 정지(2026-08-18) 이후

> 애드몹 계정이 **무효 트래픽(invalid traffic)** 사유로 정지됐다.
> 이 문서는 다음 광고망(어디든)에서 같은 일을 반복하지 않기 위한 수칙이다.
> 규칙을 바꿀 땐 이 문서와 `ui/ad_gate.dart` 를 함께 고칠 것.

## 1. 무엇이 무효 트래픽으로 잡히나

초기 앱은 **기기 수가 적다**. 그 상태에서 아래가 겹치면 광고망 입장에선
사람이 아니라 봇/자가클릭으로 보인다:

- 한 기기가 하루 수십 번 보상형 광고를 **끝까지** 시청 (우리는 기능별 상한
  합계가 40회+/일이었다: 티켓 30 + 버프 12 + 스카우트 새로고침 + 기타)
- 개발자·지인 몇 명의 기기가 전체 트래픽의 대부분
- 같은 IP·같은 기기에서 반복되는 규칙적 패턴, 광고 클릭 후 전환 0

**개발 폰 테스트는 원인이 아니다** — 디버그 빌드는 `NoAdService`(요청 자체가
없음)로 돌고, 실광고 단위가 주입 안 되면 구글 공식 테스트 단위로 뜬다.
문제는 **스토어 버전을 본인/지인 기기에서 실사용**하며 광고를 돌린 것 +
빈도 상한이 광고망 기준으로 너무 높았던 것.

## 2. 앱에 박아 둔 방어 (광고망 무관)

`ui/ad_gate.dart` — 모든 보상형 광고가 거치는 단일 관문:

| 방어 | 값 | 이유 |
|---|---|---|
| 연속 시청 쿨다운 | 45초 | 기계처럼 보이는 연속 패턴 차단 |
| 기기 일일 총량 | 20회 | 어떤 기능 조합으로도 이 위를 못 넘는다 |
| 완료만 카운트 | — | 실패·중도 이탈은 트래픽으로 안 잡힘 |

이 수치는 밸런스가 아니라 **계정 생존 조건**이라 JSON 이 아닌 코드에 있다(§6 예외).
광고망을 바꿔도 `AdService` 구현만 갈아끼우면 이 관문은 그대로 산다.

`domain/admob_ad_service.dart` — `--dart-define=AD_TEST_DEVICES=해시1,해시2` 로
테스트 기기를 등록하면 **릴리즈 빌드·실광고 단위여도 테스트 광고**가 나온다.
기기 해시는 실기기에서 광고를 한 번 요청하면 logcat 에 찍힌다.

## 3. 사람이 지킬 것

1. **본인·가족·지인 기기에서 실광고를 보지 않는다.** 테스트가 필요하면
   반드시 그 기기를 `AD_TEST_DEVICES` 에 등록하고 빌드한다.
2. **광고를 보라고 유도하는 문구·배치 금지**("여기 눌러서 보상!" 화살표 등).
   보상형은 유저가 스스로 선택해야 한다.
3. **에뮬레이터에서 실광고 금지.**
4. 새 기능에 광고 보상을 붙일 땐 `watchAdForReward` 를 반드시 거친다 —
   우회 경로를 만들면 총량 방어가 뚫린다.

## 4. 애드몹 계정 관련 (중요)

- **새 애드몹 계정을 만들지 말 것.** 정지 상태에서의 재가입은 "우회"로 간주돼
  영구 정지로 번진다. 다른 회사 광고망(유니티 애즈, 앱러빈 MAX, 아이언소스)은
  무방하다.
- 이의신청: AdMob 고객센터의 **Invalid activity appeal** 폼으로 제기할 수 있다.
  30일 정지인 경우 기간 후 자동 복귀되기도 한다. 복귀해도 위 수칙은 유지.

## 4.5. 2026-08-18 후속 결정 — 광고 없는 운영으로 전환

새 광고망을 붙이는 대신 **광고를 접고 IAP 로 간다**(사장님 결정). 광고 자리는
전부 무료 지급 + 하루 상한으로 바뀌었고, 문구도 "무료" 계열로 교체됐다.
아래 §5 는 나중에 광고를 되살릴 때를 위해 남긴다 — 그날이 오면 ARB 문구부터
광고용으로 되돌려야 한다(무료라고 써 놓고 광고를 틀면 기만이다).

## 5. 다음 광고망 붙일 때

`AdService` 인터페이스(`domain/ad_service.dart`)의 구현 클래스 하나만 만들면
된다(`admob_ad_service.dart` 와 형제). 반드시 확인할 것:

- [ ] 그 SDK 의 **테스트 모드/테스트 기기 등록** 방법부터 찾는다
- [ ] 실광고 단위 ID 는 dart-define 주입, 없으면 테스트 단위 폴백 (기존 패턴)
- [ ] 디버그 빌드는 여전히 `NoAdService` (main.dart `_useRealAds` 가 이미 보장)
- [ ] `watchAdForReward` 관문을 그대로 쓴다 — 쿨다운·총량이 여기 있다
