# 1.0.21 폰 확인 체크리스트

> 설치 빌드: profile(`com.bugchamp.app.dev` — 스토어 앱과 따로 깔림, 홈 ⚙ 설정 → **개발자 모드**가 열림)
> 🔌 표시 = **서버가 있어야** 확인되는 항목. 지금 빌드는 서버에 붙지 않습니다(운영 서버가 아직 1.0.20이라, 새 세이브 값이 지워지는 것을 막으려고).
> 🔌 항목은 1.0.21 서버를 배포한 뒤 서버 주소를 넣은 빌드로 다시 확인합니다.

준비(개발자 모드):
- [ ] 채집함 → **채우기(종별 3)** — 곤충·알이 여러 마리 생김
- [ ] 개체 등급 → **정수 +200(전 종)·물약 +10**
- [ ] 재화 추가 → 골드·재료·젤리·화석 넣기
- [ ] 강화 전부 최대 · 스킬 전부 해금 (필요하면)

---

## 1. 알 · 부화
- [ ] 채집함에서 **알**을 누르면 능력치 9칸·크기·펫 효과%·훈련 칸이 **숨겨져** 있음
- [ ] 알에서도 **이색(무지개·알비노)·기질·오행·성별**은 그대로 보임
- [ ] 알 상세 창의 "장착" 자리에 **부화기 버튼**이 있음 (빈 칸이면 넣기 · 꽉 차면 확장 · 부화 중이면 진행 표시 · 다 되면 받기)
- [ ] 부화 중인 알 상세에서 "부화 중"이 **두 번 보이지 않음**
- [ ] 알은 **펫으로 장착되지 않음** (자동 장착 후보에서도 빠짐)
- [ ] 부화기 캡슐 · 알 고르기 창 · 부화 확인 창 세 곳에서 **이색 알이 이색으로** 보임
- [ ] 알 고르기 창에서 **크기 정렬이 없음** (크기를 보고 고르지 못하게)
- [ ] **부화 공개 연출**: 받기를 누르면 능력치 9칸이 하나씩 차오름 · 평균 85↑이면 반짝 문구 + 효과음
- [ ] 여러 마리를 한꺼번에 받으면 차례로 보여 주고 **"모두 건너뛰기"**로 끝낼 수 있음
- [ ] 새로 주운 야생 알·짝짓기 알은 전부 **일반 등급**으로 나옴 (뽑기·결제 알은 예전처럼)

## 2. 개체 등급 · 정수
- [ ] 등급 올리기 비용이 **4 · 4 · 5 · 6** 정수로 보임 (일반→고급→희귀→영웅→전설)
- [ ] 곤충을 정수로 바꿀 때 받는 정수가 새 표(1·4·16·80·480 × 종 희귀도)를 따름
- [ ] 물약을 넣고 올리면 능력치 롤이 **내려가지 않음**

## 3. 펫 패시브 v2
- [ ] 새로 생긴 곤충은 같은 종이라도 **패시브 종류가 서로 다름**
- [ ] 업데이트 전부터 있던 곤충은 **종 패시브 종류 그대로** (크기만 새 규칙)
- [ ] 패시브 크기가 등급이 오를수록 커짐 · 희귀한 종일수록 큼
- [ ] **크기 재굴림**: 정수 3 또는 젤리 10 → 새 값 / 지금 값 중 고르기
- [ ] 재굴림 결과를 고르기 전에 **앱을 껐다 켜도** 다시 고를 수 있음
- [ ] 홈 상단 **전투력 · 캐릭터 카드 전투력**이 패시브를 넣은 값이고 서로 같음

## 4. 채집함 필터 · 채집망
- [ ] 필터 이름이 **"받을 종 희귀도"** 로 보임
- [ ] 채집함 목록 **보기 거르기**(등급 등)가 실제로 목록을 거름
- [ ] 채집망(직접 휘두르기)에서도 **받을 종 희귀도 필터**가 적용됨 (걸리는 종은 아예 안 나옴)
- [ ] 채집망에서도 아주 드물게 **이색**이 나올 수 있음 (확인 어려움 — 화면만 보면 됨)

## 5. 장비 · 공방
- [ ] 공방 **자동 제련 필터 창**: 쓰지 않는 옵션 4종이 사라짐 · 체크한 대로 남기고 버림
- [ ] 새 옵션 **"스킬 쿨타임 감소"** 가 장비에 붙어 나옴
- [ ] 쿨감 장비를 끼면 **스킬 설명의 쿨타임 숫자가 줄어서** 보임 · 실제 사냥에서 스킬이 더 자주 나감
- [ ] **별 재료 이월**: 이번 별 몫을 넘겨 먹여도 쌓임 (만렙까지 남은 합까지) · 강화 중에도 쌓임
- [ ] 재료가 다 모이면 **"★ 준비 완료"** 표시 · 안내 문구는 **다 모인 그 순간 한 번만** 뜸
- [ ] 같은 등급 장비로 바꾸면 별·별 재료를 이어받고, 다른 등급이면 확인 창이 뜸

## 6. 요정 🔌
- [ ] 요정 재굴림에 **속성석을 함께 쓰는** 선택이 있음 (젤리 20 + 속성석 1)
- [ ] 재굴림 결과 부가 능력치가 **이전보다 내려가지 않음** (칸마다 큰 쪽)
- [ ] 합성 재료가 **모두 같은 부가 능력치**면 결과도 그 부가로 확정

## 7. 결투 · 훈련
- [ ] 훈련소에 새 칸 **"지휘"** 가 있음 · 기질에 따라 상한이 ±2 다름
- [ ] 결투 탭 출정 칸 곤충에 **역할 뱃지(공격형·방어형·체력형)** 가 보임
- [ ] 던지기 곤충의 추천 배분 ★가 **균형형**에 붙음
- [ ] 🔌 3마리 결투에서 **팀 역할 오라**가 붙음 (출전 곤충마다 팀 전체 +%, 능력치마다 최대 20%)
- [ ] 🔌 치기 곤충이 상대를 밀치면 상대가 **잠깐 멈추고 피해**를 받음 (기술 칸을 찍었을 때)
- [ ] 🔌 리그 순위표 · 방어팀 · 결투 후보 전투력이 정상으로 보임

## 8. 왕충 선발대회
- [ ] 개발자 모드 → **왕충 선발대회 체험** 이 열림
- [ ] 대회 곤충 목록의 **전투력·순서**에 대회 전용 종 배율이 들어감
- [ ] 🔌 실제 대회 판 · 기록 저장 (⚠️ 2회차 진행 중이라 1.0.21 서버를 올리면 엔진·배율 변경이 남은 기간 판에 바로 적용됨)

## 9. 그림 (누끼)
- [ ] 스킬 아이콘 12장 안쪽에 **세이지색 덩어리가 없음** · 탈피·번데기 방벽·여왕의 부름·채집가의 손은 **새 그림**
- [ ] 곤충 옆모습 다리 사이에 **검정 덩어리가 없음** (검은 사슴벌레 몸은 그대로 검정)
- [ ] 위에서 내려다보는 **말벌 결투 그림** 허리 안쪽이 뚫림
- [ ] 황금 장수풍뎅이 스킨 크림색 테두리가 없어짐
- [ ] 메뚜기류 **애벌레 단계** 그림이 체크무늬 없이 투명

## 10. 업데이트 전 세이브 (사장님 실제 세이브로 보면 좋음)
- [ ] 예전에 펫으로 장착해 둔 **알이 자동으로 장착 해제**됨
- [ ] 예전 곤충의 패시브 값이 새 규칙으로 바뀌어 보임 (대부분 낮아짐 → 출시 공지에 적기)
- [ ] 방치하다 돌아왔을 때 **방치 보상 골드가 되돌아가지 않음** (🔌)
