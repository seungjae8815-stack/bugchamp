# 암수 차이(크기·결투 무게·도감·그림) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 종마다 암컷 크기 범위를 두고, 암컷 곤충의 크기(mm)·결투 무게·도감 기록·성충 그림이 성별을 따르게 한다. 기존 암컷은 무게가 변하지 않게 옮긴다.

**Architecture:** 성별 범위와 "같은 성별 범위 안의 위치(frac)"를 `Species` 한 곳(core_models)에 두고, 롤·짝짓기·스탯 배율·검증·결투 무게·짝짓기 평균이 모두 그 함수를 쓴다. 결투 엔진(`DuelBug`)은 mm 를 그대로 쓰므로 **수컷 환산 mm**(같은 frac 의 수컷 크기)를 넘긴다 — 엔진·시뮬 수식은 안 바뀐다. 기존 암컷은 세이브 표식 `sxm`(feat 29) 아래 한 번만 frac 을 보존해 암컷 범위로 옮기고, 서버는 구버전 업로드에서 되돌리지 않는다. 그림은 `{id}_female_adult*.webp` 가 있으면 쓰고 없으면 수컷 그림.

**Tech Stack:** Dart pub workspace(core_models → core_save/core_battle → app/server), Flutter, `dart test`/`flutter test`.

**Spec:** `docs/superpowers/specs/2026-10-22-research-lab-design.md` §12.

## Review Focus

1. **옛 암컷의 무게 불변**: 마이그레이션 전후 `maleEquivalentMm` 이 같아야 한다(Task 2 테스트 `migrateFemaleSizes keeps male-equivalent mm`).
2. **구버전 앱 업로드가 마이그레이션을 되돌리지 않는다**: feat<29 클라이언트가 수컷 범위 mm 로 같은 id 를 올려도 저장본 mm 유지(Task 3 테스트).
3. **짝짓기 자식이 성별 범위 밖으로 나가지 않는다**: 큰 수컷 × 작은 암컷에서 암컷 자식이 암컷 최대를 넘지 않는다(Task 1 테스트).
4. **암컷 범위가 없는 종(장수꽃무지)**: 모든 경로가 수컷 범위로 떨어진다(Task 1 테스트 `species without female range`).
5. **알비노/황금 스킨을 가진 암컷**: 그림 사슬이 암컷 기본 그림 + 색 필터로 떨어져야 한다(Task 6 — `bugPoseImage` 경로 순서, 수동 확인 항목).

**Interfaces:**
- Produces (Species):

  - `({double min, double max}) sizeRangeFor(Sex sex)` — 암컷이고 암컷 범위가 있으면 그것, 아니면 수컷(`sizeMinMm`/`sizeMaxMm`).
  - `double sizeFracOf(IndividualBug bug)` — `((bug.sizeMm − r.min) / (r.max − r.min)).clamp(0,1)`, `r = sizeRangeFor(bug.sex)`; 퇴화 범위(max ≤ min)면 0.5.
  - `double sizeForFrac(Sex sex, double frac)` — `r.min + frac.clamp(0,1) × (r.max − r.min)`.
  - `double maleEquivalentMm(IndividualBug bug)` — `sizeForFrac(Sex.male, sizeFracOf(bug))`. 결투 무게·짝짓기 평균이 쓴다.
  - `double remapFromMale(double maleMm, Sex sex)` — 수컷이면 `maleMm` 그대로, 암컷이면 `sizeForFrac(Sex.female, (maleMm − sizeMinMm)/(sizeMaxMm − sizeMinMm))`.
- Produces (IndividualBug): `statMultiplier(species)`·`integrityError` 가 `species.sizeRangeFor(sex)` 를 쓴다. `roll`/`breed` 는 기존처럼 수컷 범위로 크기를 굴리고 성별이 정해진 뒤 `species.remapFromMale(size, sex)` 를 적용한다.
