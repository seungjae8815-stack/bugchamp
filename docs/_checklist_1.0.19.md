# 1.0.19 확인 체크리스트 (1.0.18 → 1.0.19 변경 전체)

> 기준: 1.0.18 출시(20260944, 2026-10-10 운영 서버 00126) 이후 ~ 최신 main(2026-10-10 출시 전 점검 반영).
> 폰 확인은 **개발용 앱 + 시험용 서버(bugchamp-server-dev) + 오리 계정**으로.
> ⚠️ 개발용 앱으로 확인하는 동안 **같은 계정으로 스토어 앱(1.0.18)을 켜지 않는다** — 운영 서버(옛 코드)가 새 필드(별·정성·초월·미션 교체)를
> 모르고 저장본을 덮을 수 있다. 오리 계정만 쓴다.

## A. 장비 (가장 꼼꼼히 — 새 시스템 3개)
### 다듬기
- [ ] 장비 상세 옵션 줄 옆 다듬기 아이콘 → 다듬기 창
- [ ] 종류 칩(무작위 + 옵션 종류들)이 화면 컨셉에 맞는 칩으로 보인다 · 종류 지정 시 비용 ×3 안내
- [ ] 화석 비용 = 100 × (등급+1)(풀잎 100 · 호박 1,000) · 젤리 15(종류 지정 45) · 화석이 모자라면 젤리 버튼만 쓸 수 있다
- [ ] 굴린 뒤 "이전 값 / 새 값" 둘 중 고르기 — 이전 값을 고르면 수치가 그대로 남는다
- [ ] 같은 줄을 다듬을수록 정성 표시가 오르고(최대 10) 낮은 값이 덜 나온다
### 별 강화(옛 이름 환생)
- [ ] 모루 결과 창에서 같은 부위 장비를 **별 재료**로 넣기 · 자동 제련에서 걸러진 장비도 낀 장비의 별 재료로 쌓인다
- [ ] 1성 100개 → 150 → 200 → 250 → 300 · 재료가 다 차면 "강화 시작" → 타이머
- [ ] 강화 시간이 장비 등급마다 다르다(호박 1성 2시간 ~ 5성 24시간, 풀잎은 그 0.2배) · 젤리 즉시(공방 등급업과 같은 값표, 시간당 2 · 최소 5)
- [ ] 강화 중에는 재료를 더 못 넣는다 · 끝나면 별 +1 · 별 1개마다 옵션 효과 +4%(회피 제외)
- [ ] **새 장비로 바꾸면 별이 0** 으로 시작한다(이어받기 없음)
- [ ] 장비 상세(캐릭터 화면)에 별 줄·강화 칸이 보인다
### 공방 초월
- [ ] 공방 최대 등급(20등급)에서만 초월 칸이 보인다 · 경고 문구(빨강) · 화석 10,000(다음 단계 20,000 …)
- [ ] 누르면 확인 창 한 번 더 → 초월 → **낀 장비·모루 전부 사라짐** · 공방 풀잎(0)부터 · 화석 차감
- [ ] 초월 후 옵션 "/최대" 표시가 +15% 오른 값 · 새로 뽑은 장비가 예전 최대치를 넘을 수 있다
- [ ] 5단계 뒤 "공방 초월 완료 — 옵션 최대치 +75%"
### 판매
- [ ] 장비 여러 개를 팔면 얻은 재료가 **한 창에 합쳐** 뜬다(창이 여러 번 안 뜬다)
- [ ] 장비를 팔 때 다음 장비까지 사라지지 않는다(버그 수정)

## B. 사냥 (적응형 위협 제거 — 모든 유저가 체감)
- [ ] 근성·맷집을 올리면 몬스터 한 대의 피해가 **바로 줄어든다**(예전엔 같이 세져서 그대로였다)
- [ ] 회복력 효과가 전보다 크다(2.5배)
- [ ] 난이도 첫 보스가 조금 더 단단하다(쉬움 사냥터 1 보스 약 50분 유지)
- [ ] 사냥터 2·3 도착 직후 바로 죽지 않는다(시뮬 도착 점검 41곳 양호 · 사망 0)
- [ ] 번데기 방벽: 레벨을 올리면 무적 시간이 늘어난다(스킬 상세 숫자)

## C. 미션 · 스킬
- [ ] 미션 목표가 터무니없이 크지 않다(사냥 최대 1,000 · 강화 최대 50, 남은 강화 레벨보다 크지 않음)
- [ ] 미션 "바꾸기" → 확인 창(줄바꿈 정상) → 젤리 5 → 다른 미션
- [ ] 미션 보상: 사냥 미션 골드·강화 미션 키틴이 **지금 사냥터 10분치**(받을수록 커지지 않음 — 받은 뒤 팝업 금액 그대로 남는다, 1~2분 뒤 되돌아가지 않음)
- [ ] 제련 미션 젤리 하루 2번 → 세 번째는 "오늘 미션 젤리 2번을 다 받았어요" 안내 + 젤리 없이 다음 미션 · 미션 줄에 "오늘 젤리 다 받음" · 다음 날 다시
- [ ] 만능 조각만 있는 스킬도 해금 버튼이 뜨고 해금된다
- [ ] 조각 승급 창에서 하위 → 상위 칸이 잘 눌린다

## D. 결투 · 훈련
- [ ] 전투력 숫자가 바뀌었다(실전 전투력 — 모든 능력치 반영) · 결투 후보 색(초록·빨강)이 전력 차이에 맞다
- [ ] 순위표 상대를 누르면 프로필이 **바로** 뜬다
- [ ] 훈련 포인트 예산이 모든 곤충 같은 기준(5성·80레벨·돌파4 = 102) · "보너스 포인트" 줄 없음
- [ ] 102를 넘게 찍혀 있던 곤충: 넘친 만큼 줄어 있고 **무료 다시 찍기 1회**
- [ ] 마지막 돌파·레벨 상한에 닿은 곤충에 "Lv.85 달성 → +1" 안내가 안 뜬다
- [ ] 기질 균형: 서버 배포로 우직 밀림 저항 0.35 → 0.25(우직이 전보다 덜 버틴다 · 판정은 서버라 앱 업데이트 전에도 적용)
- [ ] 결투석 화면: 얻는 곳 안내 줄 · 오행 고를 때 이기는/지는 오행·배율 · 기질 고를 때 싸우는 방식·칸 상한 보정
