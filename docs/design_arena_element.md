# 경기장 오행 (2026-10-16 사장님 확정 — "판마다 무작위 경기장")

## 문제
경기장 그림은 오행 5종(arena_wood·fire·earth·metal·water)이 있지만 **보기만** 다르다 — 결투는 상대 첫 곤충 오행,
대회는 늘 내 곤충 오행으로 그렸다. 효과가 없어 "어떤 오행을 낼까"라는 선택이 없었다.

## 규칙
- 결투 **경기마다** 경기장 오행 1개 — 서버가 정한다(제안 `/duel/offer` 의 비밀 seed, 앱이 고를 수 없다). 후보 화면에 경기장을 보여 준다.
- 효과(체력·공격·방어): 경기장과 **같은 오행 곤충 +10%** · **경기장이 이기는(상극) 오행 곤충 −10%**. 나머지 그대로. 양쪽 모두 같은 규칙.
  수치는 `battle.json → duel.arena`(same 0.10 · restrained 0.10). 곤충끼리 상극(×1.2)은 그대로.
- 대회: **웨이브마다** 경기장이 바뀐다(회차 seed — 모두 같은 웨이브에 같은 경기장). 적은 이미 웨이브마다 오행이 돈다.
- 방어팀·야생 팀도 같은 규칙. 판정은 서버 — 앱은 재생만(같은 함수).
- ⚠️ 앱·서버 같은 날 배포(결투 판정). 구버전 앱은 경기장을 모르지만 판정은 서버라 결과는 같다(그림만 옛 방식).

## 측정
`duel_build_sim` 에 경기장 넣고 — 같은 오행 팀 대 다른 오행 팀 승률, 대회 평균 웨이브(18.5 유지 확인).
