# 곤충 배틀 스타디움 — 결투(PvP) 전면 개편 설계

> 2026-09-28 사장님 확정: **1:1 · 3판 2선승 · 위에서 내려다본 원형 경기장 · 오행은 상극만 · 던지기 게이지 있음**.
> 공방회 스탠스 RPS·기력·상생 순서 시너지·수동 턴 전투는 **PvP 에서 폐지**한다.
> ⚠️ 왕충 선발대회(2회차 10-05 ~ 10-18)는 **옛 엔진 그대로**다 — 실물 경품이 걸린 순위전을 도중에 바꾸지 않는다.
> 이 문서가 승인되면 CLAUDE.md §2.3 을 이 내용으로 다시 쓴다.

## 1. 한 판의 모습

1. 경기 전: 곤충 3마리의 **출전 순서**를 정한다. 상대 순서는 보이지 않는다(블라인드 — 심리전은 여기서 난다).
2. 판마다 1번 대 1번, 2번 대 2번, 3번 대 3번. **두 판을 먼저 이기면 끝**(2:0 이면 3판째 없음).
3. 판 시작: 캐릭터가 발사대 앞에서 곤충을 **던진다** — 게이지 타이밍을 맞추면 첫 돌진이 세진다.
4. 곤충은 경기장 가장자리에서 떨어져 경사를 타고 미끄러지고, 서로를 찾아 **부딪힌다**.
5. 승부가 나는 방법 셋:

| 결판 | 조건 | 주로 내는 쪽 |
|---|---|---|
| **장외** | 몸 중심이 경기장 테두리 밖으로 나감 | 집기(밀어내기) · 던지기(내던지기) |
| **뒤집기** | 들이받혀 배가 드러남 | 치기(뿔로 뒤집기) |
| **기절** | 체력(스태미나) 0 | 누구나 — 부딪힐 때마다 깎인다 |

시간(`duel.roundSeconds`, 초안 30초)이 끝나면 **남은 체력 %** 가 높은 쪽, 같으면 **SPD** 가 높은 쪽이 이긴다.

## 2. 곤충 데이터가 전투에서 하는 일 (새 데이터 없이)

| 데이터 | 전투에서 | 비고 |
|---|---|---|
| **사이즈(mm)** | **무게**(밀림·장외 저항)와 **몸 반경** | 도감 "최대 크기"가 처음으로 전투 가치를 갖는다 |
| HP | 체력(스태미나) | 0 이면 기절 |
| ATK | 부딪히는 힘(피해·밀어내기·뒤집기 힘) | |
| DEF | 버티기(밀림 저항·피해 감소·뒤집기 저항) | 피해 = `ATK × … × 100/(100+DEF)` 모양 유지 |
| SPD | 돌진 속도·다음 돌진까지 간격 | |
| **주특기 치기** | 돌진이 빠르고, 부딪힐 때 **뒤집기 판정** | 장수풍뎅이·사마귀·장수말벌 |
| **주특기 집기** | 부딪히면 **물고 버티며 테두리로 민다**(잡기 시간 동안) | 사슴벌레·하늘소·물장군 |
| **주특기 던지기** | 가끔 **들어 올려 바깥쪽으로 내던진다**(쿨타임 김, 한 방) | 톱·미야마·두점박이 사슴벌레, 방아깨비 |
| **기질** | 싸움 성향(아래 표) | |
| **오행** | **상극이면 피해·밀어내기 ×`restrainMult`(1.5)** | 상생 순서 시너지는 폐지 |
| 부위 강화·특성·이색 | 지금처럼 HP/ATK/DEF/SPD 배율 | `buildBattleBug` 스탯 계산을 그대로 공유 |

**기질 → 싸움 성향**

| 기질 | 성향 |
|---|---|
| 호전적 | 쉬지 않고 돌진. 돌진 간격 짧음, 가장자리를 신경 안 씀 |
| 신중 | 가장자리에서 멀어지려 함. 상대가 돌진하면 옆으로 비킴 |
| 교활 | 상대 등 뒤·옆으로 돌아 들어감(측면 충돌은 밀어내기 보너스) |
| 우직 | 경기장 가운데를 지킴. 밀림 저항 보너스, 돌진 적음 |
| 변덕 | 매 판 위 넷 중 하나를 무작위로(시드) |

> ⚠️ 모든 무작위는 **서버가 정한 시드**로만(§5 결정론). 기질·특기 판정도 같은 `Random(seed)`.

## 3. 던지기 게이지

- 좌우로 오가는 바늘을 멈춘다. 가운데 초록 구간일수록 **첫 돌진 속도 보너스**가 크다(상한 `duel.launchBonusMax`, 초안 +10%).
- 결과를 뒤집을 크기가 아니다 — "잘 던졌다"의 손맛. 방어 측(상대 AI)과 **자동 결투**는 고정값(`duel.launchAuto`, 초안 0.6)을 쓴다.
- 판마다 던진다(3판이면 3번). 자동 결투(빠른 결투)는 게이지 없이 한 번에 3판.
- ⚠️ 게이지 값은 **앱이 보내는 입력**이라 매크로로 늘 만점을 낼 수 있다. 상한이 작아서(10%) 받아들인다.

## 4. 흐름 (서버 권위 — 앱은 재생만)

```
앱                                  서버
 ├ 출전 순서 3마리 + 상대 선택 ───▶ /duel/start  : 편성 검증 · 티켓 · 트로피/부상 선차감 · 세션(시드)
 │                                  ◀── 세션 id, 상대 3마리 공개 정보(순서는 판마다 공개)
 ├ 1판 게이지 값 ─────────────────▶ /duel/throw  : 1판 물리 계산 → 궤적 + 결판
 │  (궤적 재생)                     ◀── 궤적, 결판, 누적 스코어
 ├ 2판 게이지 값 ─────────────────▶ /duel/throw  … 2선승이면 보상 확정 · 세션 종료
 └ (자동 결투)  ──────────────────▶ /duel/auto   : 3판을 한 번에(고정 게이지)
```

- 옛 `/battle`·`/battle/manual/*` 는 **대회가 안 쓴다** — PvP 전용이라 새 엔드포인트로 교체하고, 1.0.13 이하가
  부르면 `update_required` 로 거부한다(강제 업데이트와 함께 나간다).
- 도중에 앱을 끄면: 세션은 남고, 선차감된 트로피·부상은 그대로(지금 수동 전투와 같은 규칙 — 불리하면 끄는 꼼수 차단).
- 보상(`pvpReward`)·트로피·티켓·시즌 순위 기록(`_recordPvpScore`)·리그는 **그대로** 쓴다. 승패만 "3판 2선승" 결과로 바뀐다.
- 부상: **진 판의 곤충**이 부상(등급별 시간, 지금과 같은 `injuryDuration`). 이긴 곤충·안 뛴 3번째는 무사.

## 5. 물리 엔진 (`core_battle/lib/src/duel/`, 순수 Dart)

- 2D 원판(반지름 `arenaRadius`) + 가운데로 모이는 **경사 힘**(`bowlPull`) + 마찰(`friction`).
- 곤충 = 원(반지름 ∝ 사이즈), 질량 ∝ 사이즈^`massExp` × (1 + DEF 보정).
- 고정 시간 간격(1/30초), 한 판 최대 `roundSeconds × 30` 틱. `sin/cos` 같은 초월 함수는 쓰지 않는다(벡터·제곱근만) —
  서버가 계산하고 앱은 **서버가 준 궤적을 재생만** 하므로 기기마다 계산이 달라질 일은 없지만, 테스트 재현성을 위해.
- 충돌: 탄성 충돌 + 상대 속도 비례 피해. 치기는 충돌 시 뒤집기 확률 `flipChance(ATK/DEF, 질량비, 상대속도)`.
  집기는 잡기 상태(`gripSeconds`) 동안 테두리 방향으로 미는 힘. 던지기는 쿨타임마다 바깥쪽 큰 충격량 + 공중 시간.
- 출력: 3틱마다 한 프레임(초당 10) — `[x, y, 방향, 체력%, 상태]` × 2마리 + 사건 목록(충돌·잡기·던지기·뒤집힘·장외·기절).
  좌표는 정수로 양자화해 응답 크기를 줄인다(한 판 ≈ 5~10KB).
- 수치는 **전부 `battle.json → duel`**(§6). core_battle 은 core_run 을 모르므로 `DuelParams.fromJson` 을 core_battle 에 두고
  앱·서버가 JSON 을 읽어 넘긴다.

### 밸런스 도구 `core_battle/tool/duel_sim.dart`

손으로 맞추지 않는다. 목표(초안):
- 같은 전력이면 치기·집기·던지기 **서로 승률 40~60%**(가위바위보가 아니라 약한 상성).
- 전력(스탯 합) +20% 면 승률 약 70%, +50% 면 약 90% — 게이지로는 못 뒤집는다.
- ~~같은 종이면 사이즈 최대 vs 최소 승률 60% 안팎~~ → **불가능한 목표였다(2026-09-28 측정).** 사이즈는 §2.1 규칙대로
  이미 스탯에 ×0.85~1.20(최대/최소 = +41%)으로 들어가서, 무게 효과를 꺼도 76~100% 다. 무게는 조금만 더한다(`massExp` 0.3).
  사이즈를 덜 결정적으로 하려면 §2.1 스탯 배율부터 바꿔야 한다(사장님 결정 사항).
- 결판 비율: 장외·뒤집기·기절·시간 판정이 한쪽으로 쏠리지 않게.

## 6. 방어팀과 야생 상대

- **방어팀을 곤충 id 로만 등록**하고, 싸울 때 서버가 **그 유저의 세이브에서** 스탯을 계산한다(`validateTeam` 과 같은 검증).
  지금은 앱이 계산한 스탯을 Supabase 에 직접 올리고 서버가 그대로 믿는다 — **방어 스탯 위조 구멍**을 이번에 닫는다.
- 방어 순서도 방어팀 등록 때 정한다(편성 화면에서 "방어 순서"로 저장).
- 야생 상대(`buildWildTeam`): 내 상위 3마리 평균 × 티어 배율로 3마리 — 1:1 에 맞게 판마다 한 마리씩.

## 7. 화면·연출 — 던질 때는 위에서, 싸울 때는 옆에서 (2026-09-28 사장님 결정)

- **편성**: 3칸 = 출전 순서(1·2·3번). 상생 바·장소 칩 제거. 오행 상극은 상대 공개 후 판마다 표시.
- **경기장 오행**: 오행 5종 경기장(아래 아트) — 상대 리드 곤충 오행으로 고른다(장식만, 보너스 없음).
- **던지기(위에서)**: 화면 아래 캐릭터가 던지는 동작 → **위에서 본 경기장** 위로 곤충(위에서 본 그림)이 포물선으로 떨어짐
  (그림자 커졌다 작아짐) → 착지 먼지. 게이지는 이 장면에서.
- **전환**: 착지하는 순간 카메라가 내려오는 짧은 연출로 **옆에서 본 경기장**으로 넘어간다.
- **싸움(옆에서, 2.5D)**: 엔진은 그대로 원판 위 2D 좌표다. 화면은 낮은 각도에서 본 납작한 타원 무대 —
  좌우(x)는 화면 좌우, 앞뒤(y)는 살짝 위아래 + 크기 차이(벨트스크롤 액션처럼). 앞에 있는 곤충을 나중에 그린다.
- 곤충은 **기존 옆모습 3자세**(대기·공격·피격, `bugPoseImage`)를 쓴다. 상대 쪽을 보도록 좌우만 뒤집는다.
  충돌 순간 공격 자세, 맞으면 피격 자세, 평소엔 대기 + 코드로 살짝 통통 튀기(걷는 느낌).
- 결판: **뒤집힘**(옆모습을 180° 돌려 다리가 하늘로 + 빙글) · **장외**(무대 밖으로 튕겨 나가며 슬로모션) · 기절(별).
  잡기는 두 몸이 붙어 끌려가고, 던지기는 상대가 위로 떴다 떨어진다(공중 = 그림자와 몸 사이가 벌어짐).
- 판 사이: 스코어 `1 : 0` 과 다음 상대 공개.
- 알고 가는 한계: 옆으로 돌아 들어가는 움직임(교활·신중)은 앞뒤 깊이로만 보여 위에서 볼 때보다 덜 선명하다.

| `battle.json → duel` 수치 · §2.3 문서 | `manualTurnSeconds`·`locationAffinityBonus` 는 쓰는 곳이 없어지면 정리 |

함께 고치는 기존 문제(조사에서 발견):
- 서버 `/battle` 이 `enhance` 계수를 안 넘긴다(기본값이 같아 드러나지 않았을 뿐).
- 실유저 상대는 서버에서 보상 배율 1.0 고정인데 화면은 티어 보상을 보여 준다.
- 야생 파워 식(서버)과 스카우트 파워 식(앱)이 다르다.
- `injured` 가 서버 소유 필드가 아니다(업로드로 부상을 지울 수 있는지 확인).
