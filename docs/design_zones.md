# 사냥터·보스 구조 — 2026-09-14 사장님 확정

> 스테이지 1000개 × 20마리 대신 **난이도마다 사냥터 10 + 최종 보스 1 = 11**.
> 사냥터 안의 몬스터는 세기가 **평탄**하고 무한히 나온다. 재화를 모아 강화한 뒤
> "보스 도전"을 눌러 깨면 다음 사냥터가 열린다.

## 확정 사항

| 항목 | 결정 |
|---|---|
| 구성 | 쉬움/보통/어려움/극한 × (사냥터 10 + 최종 보스 1) = 보스 44마리 |
| 사냥터 안 | 몬스터 세기·보상 **평탄**, 무한 |
| 사냥터 사이 | 몬스터 세기 **와** 보상이 한 단계씩 오른다 — 낮은 사냥터에 눌러앉아 모으지 못하게 |
| 보스 도전 | 그 사냥터에서 **100마리**를 잡아야 열린다(`bossUnlockKills`). 실패 벌칙 없음, 무한 재도전 |
| 몬스터 세기 | **고정**(적응형 끔). 내가 성장해서 넘는다 — 그래야 키우는 맛이 난다 |
| 기존 유저 | 전원 사냥터 1 부터(`kZoneEpoch`). 강화·장비·재화는 그대로라 빠르게 뚫는다 |
| 랭킹 진행도 | "난이도 · 사냥터 n" |
| 트로피 | 매주 월요일 09:00 KST 에 0 으로 |
| 로드맵 | 보스 11칸 실루엣, 점령하면 드러난다 |

## 구현 — 기존 축을 재사용한다

사냥터 k = 스테이지 `(k-1) × worldSize + 1`. 스테이지 번호는 사냥터 안에서
**오르지 않고**, 보스를 깨면 `worldSize`(100)만큼 뛴다. 덕분에:

- 지역(`stagesPerRegion = 100`) = 사냥터 단위로 바뀐다.
- 월드 배율(`worldHpMult`·`worldGoldMult`) = **사냥터 사이의 계단**이 된다.
- 로드맵 챕터(100 스테이지 폭, `nodeStep 100`) = 사냥터 하나에 보스 칸 하나.
- 랭킹의 `stage` 열은 그대로 두고 표기만 바꾼다(`progressLabel`).

사냥터 안이 평탄한 것은 `hpGrowth`·`goldGrowth` 를 1.0 으로 둬서 얻는다.
적응형 체력·위협은 `hpAdaptTargetHits 0`·`threatAdaptTargetPct 0` 으로 끈다.

### 상태(세이브)
- `zoneKills` — 지금 사냥터에서 잡은 수(도전 게이지). 보스를 깨거나 사냥터를 옮기면 0.
- `zoneEpoch` — 구조 세대. `kZoneEpoch` 보다 낮으면 앱 로드·서버 로드 양쪽에서
  `applyZoneEpoch` 가 진행도(스테이지·회차·게이지)를 처음으로 되돌린다.
  스키마 버전은 올리지 않는다(구버전 앱이 서버 세이브를 못 읽고 죽는다).

### 흐름
1. 사냥터: `_spawn` 은 보스를 내지 않는다(`_bossChallenge` 가 켜질 때만).
   처치마다 `applyReward(zoneKill: true)` 가 게이지를 올린다.
2. 도전: HUD 의 [보스 도전] → `_startBossChallenge` → 보스 스폰.
3. 승리: `advanceZone` (스테이지 +100, 게이지 0) → 챕터 클리어 보상 → 다음 사냥터.
   최종 보스면 회차 전환 안내(기존 `_tierClearPending`).
4. 패배: 벌칙 없이 사냥터로. 사냥터를 못 버티면 로드맵에서 아래 사냥터로 내려간다(`selectZone`).
5. 방치 정산: 스테이지를 밀지 않고 처치 수(→ 게이지)와 보상만 쌓는다. 앱·서버 같은 함수.

## 진행 기록

- ✅ 3단계: 강화 덧셈 전환 + 사냥터별 표(`zoneHp`·`zoneBossHp`·`zoneThreat`·`zoneGold`) —
  `balance_sim --fit-zones`. 일반 몬스터·위협 = **도착 시점** 전력, 보스 = **머문 뒤** 전력
  (둘 다 머문 뒤로 맞추면 첫 화면부터 막힌다, 2026-09-14). 위협은 다시 적응형.
- ✅ 로드맵 세로 목록 · 점령 전 실루엣 · 보스 44마리 아트와 이름표(`roadmap.json → bosses`).
- ✅ 랭킹 진행도 표기 `보통 · 사냥터 3` + 전투력, 정렬 회차 → 사냥터 → 전투력(2026-09-15).
  진행도는 역대 최고(`bestStage`).
- ✅ 곤충은 캐릭터의 첫 타 **뒤에** 따라 친다(2026-09-15 실기기 지적 — 곤충 누산기가
  이월돼 붙자마자 곤충이 먼저 쳤고, 한 방 구간에선 캐릭터가 공격 모션 없이 서 있었다).

- ✅ 보스 처치 미션 → **제련 100회(고정)** 로 교체(2026-09-15). 보스가 사냥터마다 100마리 뒤에만
  나와 목표(3→4→5…)가 안 찼고, 미션이 순서대로 돌아서 사냥·강화 미션까지 멈췄다.
  근거는 `missions.json → _forgeComment`.
